# EchoLab — A Room Changes Everything

An interactive browser-based lab that teaches signal-processing concepts through classroom acoustics. Built for the DA3021 course.

> **The core question:** move your seat, or treat the room?

---

## What the site does

The website has three tabs:

| Tab | What you do |
|---|---|
| **Explore** | Pick a seat on the classroom map, change surface absorption, and watch how the impulse response, cumulative energy, and frequency spectrum change. A convolution worked example and a sound workbench (waveform + STFT) are built in. |
| **Compare** | Save any two configurations and compare their metrics side-by-side, with aligned audio playback. |
| **Findings & method** | Read the computed results, the acoustic model, and the numerical validation checks. |

The site is fully static — Python generates the data once; the browser does everything else with no server.

---

## Quick start

**Requirements:** Python 3.9+, NumPy ≥ 1.26, SciPy ≥ 1.12.

```powershell
# 1. Install Python dependencies (once)
pip install -r requirements.txt

# 2. Generate experiment data (~30 seconds)
python simulate.py

# 3. Serve locally
.\start.ps1
```

Then open **http://127.0.0.1:8765** in a browser.

> **Important:** open via HTTP, not by double-clicking `index.html`. The site fetches audio and JSON over HTTP — opening the file directly will fail silently.

The WAV impulse responses are excluded from Git (they are large and reproducible). Re-run `simulate.py` after any fresh checkout.

## The acoustic model

The simulation uses the **image-source method** (Allen & Berkley 1979) in a shoebox room.

| Parameter | Value |
|---|---|
| Room | 6 × 8 × 3 m |
| Seats | 30 (6 rows × 5 columns) at 1.2 m height |
| Lecturer positions | Front-centre [3, 1, 1.5 m] and Front-left [1, 1, 1.5 m] |
| Surface absorption (α) | Low 0.18 · Medium 0.40 · High 0.70 |
| Reflection order | 48 |
| Sample rate | 16 000 Hz |
| Sound speed | 343 m/s |

**Key modelling choices:**
- Pressure reflection coefficient = √(1 − α); geometric spreading = 1/(4πd).
- Fractional delays use linear interpolation (introduces minor frequency-dependent error).
- A 4th-order causal 80 Hz high-pass filter removes DC buildup from positive image pulses. All exported metrics and audio include this filter.
- No furniture, scattering, air absorption, directivity, or background noise.

**Primary metric — 90% energy time (T₉₀):** time (ms) from direct arrival until 90% of the response's squared-sample energy has accumulated. This is a descriptive course-linked measure, not a standardised reverberation time.

**Optional extension — C₅₀:** 10 log₁₀(early / late energy), split at 50 ms. Available in the acoustic extension panel.

## Regenerating the synthetic voice sample

The default `dist/data/voice.wav` is Windows text-to-speech. Regenerate it on Windows if needed:

```powershell
Add-Type -AssemblyName System.Speech
$s = New-Object System.Speech.Synthesis.SpeechSynthesizer
$s.SetOutputToWaveFile("$PWD\dist\data\voice.wav")
$s.Speak('A classroom changes the sound we hear. Speech reaches us directly, and also reflects from the walls, floor, and ceiling. In this experiment, we explore how changing our position and the room absorption changes the received sound.')
$s.Dispose()
```

If the file is missing, the site shows an error and lets you switch to diagnostic clicks or upload your own audio.

## Running the checks

All checks are code-only — no browser is opened.

```powershell
# Python: verify exported WAV files match experiment.json
python checks\verify.py

# JavaScript: verify app logic, UI IDs, FFT/STFT, convolution examples
node checks\verify_frontend.cjs
node checks\verify_study.cjs
node checks\verify_timeline.cjs
node checks\verify_transport.cjs
node checks\verify_spectrogram_guide.cjs
```

The checks verify numerical correctness and that UI element IDs exist — they do not replace a visual or audio review in a browser.

**Validation summary:** order-convergence checks compare C₅₀ at reflection orders 32, 48, and 64 across 18 representative positions. The 48→64 change must stay below 0.15 dB. Latest results are in `checks/validation.json`.

---

## Limitations

- C₅₀ and T₉₀ are acoustic ratios — not listener comprehension scores.
- No measured-room validation; results describe this simplified model only.
- Level-matched playback intentionally hides absolute level differences.
- Constant frequency-independent wall absorption and linear fractional delays are simplifications.
